The Hierarchical Gaussian Filter — three layers, two directions

A 3-level binary HGF (Mathys et al. 2011, 2014), the perceptual model fit in analysis/hgf/model.py. Each layer is a Gaussian belief; the layer above sets the volatility of the one below. Predictions flow down, precision-weighted prediction errors flow up.

① Generative model — top-down

How the world is assumed to produce outcomes. Each layer is a Gaussian random walk whose variance is set by the layer above.

$$x_3^{(k)} \sim \mathcal N\!\big(x_3^{(k-1)},\; \vartheta\big),\qquad \vartheta=\exp(\omega_3)$$

Level 3 drifts on its own clock (meta-volatility ω₃).

$$x_2^{(k)} \sim \mathcal N\!\big(x_2^{(k-1)},\; \exp(\kappa\,x_3^{(k)}+\omega_2)\big)$$

★ The coupling: Level 3 sets how far Level 2 may move per trial.

$$x_1^{(k)} \sim \text{Bernoulli}\big(\sigma(x_2^{(k)})\big),\qquad u^{(k)}=x_1^{(k)}$$

Level 2's squashed value is the reward probability; the outcome is a coin flip.

② Inversion / belief update — bottom-up

On each trial: predict, measure the surprise, then update each layer by a precision-weighted prediction error.

Predict

$$\hat\mu_2=\mu_2,\quad \hat p=\sigma(\hat\mu_2),\quad \nu_2=\exp(\kappa\,\mu_3+\omega_2)$$ $$\hat\pi_2=\big(\tfrac1{\pi_2}+\nu_2\big)^{-1}$$

Update Level 2 (tendency)

$$\color{#e11d48}{\delta_1}=u-\hat p,\qquad \pi_2=\hat\pi_2+\hat p(1-\hat p)$$ $$\mu_2=\hat\mu_2+\underbrace{\tfrac{1}{\pi_2}}_{\text{learning rate}}\,\color{#e11d48}{\delta_1}$$

Update Level 3 (volatility)

$$w_2=\nu_2\,\hat\pi_2,\qquad \color{#e11d48}{\delta_2}=\big(\tfrac1{\pi_2}+(\mu_2-\hat\mu_2)^2\big)\hat\pi_2-1$$ $$\pi_3=\hat\pi_3+\tfrac12\kappa^2 w_2\big(w_2+(2w_2-1)\color{#e11d48}{\delta_2}\big)$$ $$\mu_3=\hat\mu_3+\tfrac12\,\tfrac{\kappa\,w_2}{\pi_3}\,\color{#e11d48}{\delta_2}$$

The whole idea in one sentence: the learning rate at Level 2 is 1/π₂, and it grows with the believed volatility μ₃ at Level 3 — so when the world looks unstable, beliefs update faster. That feedback from L3 → learning-rate → L2 is what makes the filter hierarchical.
